# Царински фактури

Мобилна апликација за фактури за **царински услуги** (изготвување ЕЦД, транзит, шпедиција…).
Работи во прелистувач на телефон и компјутер — нема инсталација, нема сервер, нема build.

## Што прави

- **Излезни и влезни фактури.** Излезна = твоја фирма издава. Влезна = твоја фирма прима (го внесуваш бројот од добавувачот).
- **Од фирма → до фирма.** Избираш издавач и примач од список фирми; копче „⇅ Замени“ ги менува местата.
- **Царински податоци** на фактурата: постапка, царинарница, ЕЦД / MRN, возило, фактура за стока, тарифен број, колети, тежина, вредност.
- **Ставки со ДДВ** (18 / 10 / 5 / 0 %) и посебен дел за **трошоци во име и за сметка на налогодавачот**
  (царина, ДДВ при увоз, терминал…) што не влегуваат во основицата за ДДВ.
- **Автоматски број** по издавач и година (`001/2026`, со префикс по желба).
- **Ценовник** на услуги — се додаваат со еден допир.
- **Преглед на А4**, печатење, **PDF**, и **Сподели** (Viber / WhatsApp / е-пошта на телефон).
- **Список** со филтри (излезни/влезни, фирма, месец, барање), збирови и статус платена / неплатена / доспеана.
- Износ **со зборови** на македонски.

## Како се отвора

- Локално: отвори `index.html` во Chrome / Edge / Safari.
- На телефон: постави ја папката на кој било статички хостинг (GitHub Pages, Netlify, Firebase Hosting)
  и отвори ја адресата. Во менито на прелистувачот избери „Додај на почетен екран“ — се отвора како апликација.

## Податоци

- Сè се чува во прелистувачот (`localStorage`), а ако е вклучена синхронизацијата (⚙ Подесувања) —
  и во Firebase Firestore, во колекциите `carina_companies`, `carina_services`, `carina_invoices`,
  па истите податоци се гледаат на телефон и компјутер.
- Секоја фактура ги чува податоците за двете фирми во моментот на зачувување — подоцнежна измена на фирма
  не ги менува старите фактури.
- ⚙ → „Резервна копија“ симнува JSON со сите податоци; „Врати копија“ го враќа.
- Firebase клучот е јавен по дизајн. Заштитата се прави со Firestore security rules.

## Датотеки

| Датотека | Што е |
|---|---|
| `index.html` | Изглед на апликацијата |
| `css/app.css` | Стилови (прво за телефон) + А4 лист и печатење |
| `js/app.js` | Логика: уредувач, список, фирми, ценовник, PDF |
| `js/sheet.js` | Пресметки (ДДВ, збирови) и изглед на фактурата |
| `js/store.js` | Чување податоци (localStorage + Firestore) |
| `js/words.js` | Износ со зборови |
| `sw.js`, `manifest.webmanifest` | Работа без интернет и „додај на почетен екран“ |
